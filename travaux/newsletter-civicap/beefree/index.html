Newsletter CiviCap dans Beefree

Un bloc HTML · trois gestes
  1. Dans Beefree, créer un e‑mail vide.
  2. Glisser un bloc « HTML » dans la rangée.
  3. Cliquer sur Copier le code ci‑dessous, puis le coller dans le bloc. La newsletter apparaît entière, telle quelle.
Le code de la newsletter

Avant l'envoi par Brevo, il reste le pied de l'e‑mail : le lien « Se désabonner » ([LIEN_DESABONNEMENT] dans le code) et l'adresse postale.

Pas de bloc « HTML » dans la liste ? D'après la documentation de Beefree, il fait partie des offres payantes. Dis‑le‑moi, on passera par Brevo directement.
